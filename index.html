Life Agent

A private household assistant for one family.

Life Agent reads the owner's own Gmail and Google Calendar to keep track of bills, appointments and follow-ups, and to prepare draft replies for the owner to review. It runs on a private server in the owner's home. It is not a public service, it has no sign-up, and it is used only by the people who run it.

What it does

  • Reads mail to find bills, receipts, appointments and messages that need a reply.
  • Applies labels, prepares draft replies (never sent automatically) and adds calendar events.
  • Summarizes the household's day in a daily brief.

See the privacy policy for exactly which Google data is used and where it goes.

Life Agent is a personal project, not affiliated with Google.
