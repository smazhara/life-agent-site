Privacy policy

Life Agent · Last updated: 2026-11-21

Life Agent is a private application run by one household for its own use. Only the account holders who connect their own Google accounts to it are users. This page describes the Google data it accesses and what it does with it.

Google data accessed

  • Gmail, read-only (gmail.readonly): the content and metadata of the connected user's messages, used to find bills, receipts, appointments and messages that need a reply.
  • Gmail, modify (gmail.modify): applying labels, archiving or trashing messages, and creating reply drafts. Drafts are addressed only to the original sender and are left for a person to review and send. The only mail the application sends itself is a daily summary to the household's own addresses; it does not send mail to anyone else.
  • Google Calendar: creating events on one dedicated household calendar.

Read-only and modify access use two separate grants held by two separate processes, so the component that reads mail cannot change it. The component that changes mail can only perform a fixed list of operations and never sees raw message text.

How the data is used

Data is used only to provide the features above to the account holder. It is not used for advertising, sold, or shared with anyone outside the household.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where it is stored and who else sees it

  • Extracted facts (such as bill amounts and due dates) and message metadata are stored in a database on a private server in the account holder's home.
  • To classify and summarize messages, relevant message text is sent to Anthropic, the provider of the Claude AI models, for processing. It is sent only for that purpose.
  • No other third party receives the data.

Retention and deletion

Data stays on the household's server until the account holder deletes it. Access can be revoked at any time at myaccount.google.com/permissions; the application then stops reading that account. To have stored data deleted, contact the address below.

Security

The application is reachable only on a private network, OAuth tokens are stored on the private server, and changes to mail and calendars go through a fixed, logged list of operations.

Contact

Questions about this policy, or requests to delete stored data: open an issue at github.com/smazhara/life-agent-site/issues.

Life Agent is a personal project, not affiliated with Google.
